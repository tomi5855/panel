# Panel

Panel de vida personal: el día, las finanzas, el trabajo y los hábitos de un vistazo. Es una web que se instala en la
pantalla de inicio (iPhone/iPad: Safari → Compartir → Añadir a pantalla de inicio) y funciona sin conexión.

Este repositorio solo tiene el código. **Aquí no hay datos:** viven en un repositorio privado (`usuario/panel-datos`)
que la app lee con una llave de GitHub guardada solo en el aparato.

- Lee: `panel.json`, `habitos/config.json`, `fondos/*.jpg`.
- Escribe: `habitos/registro.json`, `aprender/reacciones.json`, `hoy/hechas.json` (mezclando con lo que ya haya).
